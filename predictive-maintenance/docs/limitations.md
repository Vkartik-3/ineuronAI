# Limitations & Honest Status

This file is the single place that separates **what is proven** from **what is
prepared, simulated, or unverified**. Read it before citing any claim.

## Data & model scope

- **NASA C-MAPSS is simulated data.** Turbofan degradation is generated by a
  physics simulation, not collected from a live fleet. All accuracy/MAE numbers
  are on the FD001 test split, single seed, local CPU.
- The system is **not validated for live aircraft maintenance or any
  safety-critical decision.** It is a demonstration of ML-serving engineering.
- Model-quality numbers (MAE 9.09, within-15 = 80.1%) are reproducible via
  `ml_pipeline/evaluate/baseline_comparison.py` but are **offline evaluation**,
  not live production performance.

## What is prepared but NOT executed / unverified

- **GPU acceleration**: no CUDA device on this host. The code path exists and
  the device is selected at runtime, but a GPU throughput benefit is
  **unmeasured**. The CPU single-request path already meets the SLO, so the
  low-latency path runs on CPU. `cpu_vs_gpu_report.json` records GPU as skipped.
- **Multi-worker / multi-node scale**: the load test that WAS run used a
  single uvicorn worker on loopback (see below); horizontal scale, multiple
  workers, and cross-node behavior are **unverified**.
- **AWS deployment — DONE (then torn down).** The service was really deployed
  to ECS Fargate + ALB + ElastiCache in us-east-2, served live predictions
  (p99 261 ms, network-RTT bound), and all billable resources were destroyed.
  Evidence: `artifacts/aws_deployment_evidence.md`,
  `artifacts/deployed_api_latency.json`. Remaining unverified: a *standing*
  production deployment and same-region (non-home-internet) latency.
- **Live drift / production feedback**: the 80%-threshold retraining is driven
  by a **controlled** feedback stream, not live production labels. It is guarded
  automatic *retraining*, not automatic *promotion* — a challenger must beat the
  incumbent to be promoted.

## Boundary statements (say these out loud in an interview)

- "Local latency is local — it is not an AWS-endpoint number."
- "GPU acceleration is a supported code path, unproven on hardware here."
- "Retraining triggers automatically; promotion does not — it requires the
  challenger to win on MAE."
- "C-MAPSS is simulated; nothing here is cleared for real aircraft safety."
